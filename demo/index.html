Варианты подключения

Вариант 1: ES-модуль

Скачать ES-модуль и положить его, например, в каталог src/.

import { polyfillFlexRule } from './flex-rule-polyfill.js';

const cards = document.querySelector('#cards');
polyfillFlexRule(cards);

В HTML это может быть контейнер с карточками:

<div id="cards" class="cards">
    <article>Карточка 1</article>
    <article>Карточка 2</article>
</div>

Ваш сборщик (Vite, Webpack, Rollup и т. п.) включит импортированный модуль в итоговый bundle.

Вариант 2: обычный JS

Скачать browser-сборку и подключить её обычным тегом:

<script src="flex-rule-polyfill.browser.js"></script>
<script>
    // Polyfill and DOM references
    const { polyfillFlexRule } = window.FlexRulePolyfill;
    polyfillFlexRule(document.querySelector('#cards'));
</script>

Этот вариант не требует import и сборщика.

Размер browser-сборки: около 4,8 KB, после gzip: около 2,2 KB.
